# FFXIV 食物分类 Tag 标注

为游戏"最终幻想14"中的食物进行分类打标。

> ⚠️ **这是一项需要理解判断的任务，而非脚本批量处理。**
> 请逐条阅读食物名称和描述，利用对食物常识的理解进行语义判断，
> 而非依赖简单的关键词匹配或规则脚本。

## 数据格式

输入文件：`what-to-eat-in-ffxiv/public/data/batches/batch-*.json`

每条数据包含以下字段：

```json
{ "item": 4728, "name": "葡萄干", "description": "晒干之后的低地葡萄，甜味有所增加。" }
```

输出时直接在原文件**覆盖**，增加 `tag`（`string[]`）和 `calories`（`number`）字段：

```json
[
  {
    "item": 4728,
    "name": "葡萄干",
    "description": "晒干之后的低地葡萄，甜味有所增加。",
    "tag": ["零食"],
    "calories": 300
  },
  {
    "item": 4650,
    "name": "水煮蛋",
    "description": "白水煮熟的鸡蛋。",
    "tag": ["配菜"],
    "calories": 70
  }
]
```

## 分类体系

每个食物分配 **1 个核心 tag**，少数可给 **多个**。不使用斜线分隔的分类名。

| Tag | 涵盖范围 | 示例 |
|-----|----------|------|
| `主食` | 饭、面、面包、饼、粥等谷物类 | 煎饼、散寿司、骑士面包 |
| `肉类` | 以肉、鱼、虾、蟹等为主的主菜（烤/煎/炸等） | 栗鼠肉排、盐烤公主鳟、炸蟹饼 |
| `汤品` | 各种汤、羹、炖菜 | 清炖羊肉、白鱼汤、汤锅炖菜 |
| `沙拉` | 凉拌菜、蔬菜沙拉 | 高山萝卜沙拉、蚕豆沙拉 |
| `配菜` | 蔬菜小菜、菌菇、奶酪、蛋类等副食 | 煎鸡油菌、水煮蛋、酸泡菜 |
| `甜点` | 蛋糕、饼干、布丁、派、挞等 | 巧克力球、苹果挞 |
| `饮品` | 果汁、茶、咖啡、奶昔、酒类 | 橙汁、薄荷酸奶昔 |
| `零食` | 果干、肉干、糖果等休闲小食 | 葡萄干、牛肉干、金平糖 |

## 边界案例与分类优先级

### 1. 跨类别物品

判断逻辑：**名称和描述共同决定**。名称提供直观线索，描述揭示实际食材和烹饪方式，两者结合判断。

**复合食材的主次判断**：主要食材决定核心 tag，烹饪方式（炖/焗/烤等）不单独归类。

| 物品 | 判断依据 | 结果 |
|------|----------|------|
| 鳗鱼派 | 派皮为主 → 主食 | `["主食"]` |
| 红烩牛肉 | 牛肉为主菜 → 肉类，炖为烹饪方式 | `["肉类"]` |
| 海鲜汤 | 汤为主 → 汤品 | `["汤品"]` |
| 蛋包饭 | 饭是主体，蛋是外皮 | `["主食"]` |
| 铁锅番茄炖蛋 | 蛋类副食 → 配菜 | `["配菜"]` |
| 清炖羊肉 | 羊肉为主菜，兼有汤品属性 | `["肉类", "汤品"]` |
| 红焖皮皮拉鱼 | 鱼为主菜 → 肉类 | `["肉类"]` |

### 2. 模棱两可的分类归属

当物品无明显分类关键词时，按以下优先级推测：

| 判断方式 | 示例 |
|----------|------|
| **主要食材**：肉/鱼/虾为主→肉类，蛋/蔬菜/菌菇→配菜，汤/羹→汤品 | 烤肋排 → 肉类；蟹肉蛋羹 → 配菜（蛋为主体） |
| **谷物基底**：含有饭/面/饼/面包等→主食 | 面包丁 → 主食（无论搭配什么食材） |
| **食用场景**：正餐配菜→配菜，饭后→甜点，休闲→零食 | 小饼干 → 甜点；牛肉条 → 零食 |

### 3. 无法归类的物品

如果某食物确实无法归入任何现有分类：
- 使用最接近的分类，`tag` 中仅保留 1 个核心 tag
- 避免新增分类或使用"其他"

## 分析要点

1. **语义理解优先**：名称和描述中的关键词仅供参考，最终分类应基于对食物本身的理解。例如名称叫"鱼糕"但描述说是点心，应归为甜点而非肉类；"蛋奶酥"实际是奶酪点心，非蛋料理
2. **多 tag 限制**：仅当食物确实属于多个分类时才加额外 tag。同一维度不拆分
3. **不使用斜线**：禁止"沙拉/配菜"写法，一律用数组多元素 `["沙拉", "配菜"]`
